# 跳一下 hop!

一个无构建依赖的静态多跳检索互动 Demo。直接展开检索轮次、点击证据节点，比较单轮与多跳路径。

## 运行

在本目录执行 `python3 -m http.server 8080`，浏览器打开 http://localhost:8080 。需要通过 HTTP 服务加载 `data.json`，不建议双击 HTML。

## 场景

- 教学水果关联：手工编排，用于解释中间线索与多跳路径，不构成医学或健康因果论证。
- H174030：真实 CBP CROSS 裁定实验的增益案例回放。
- H029876：真实实验的退化案例回放。

真实数据摘自 2026-09-14 已完成的离线研究记录。前端不运行模型、不发送用户输入、不提供自动关税决定。证据图仅显示关键节点，全部本轮片段可从侧边详情展开；语义边和材料引用边分别表示。引文恢复率不等于估价准确率。

## 发布范围

仅需 `index.html`、`style.css`、`app.js`、`data.json` 与本 README。无密钥、模型权重、原始论文或私人报关材料。默认字体为本地系统中文字体，无外部资源依赖。数据来源链接指向美国 CBP 官方公开裁定记录，其结论不能直接作为中国税收案件的裁定依据。

## 交互与可访问性

三场景切换、单轮/多跳切换、逐轮展开、播放/暂停、重置、来源详情、完整片段清单、成本对比与边界说明。使用原生按钮和 details；支持键盘焦点、减少动态效果偏好和手机布局。
