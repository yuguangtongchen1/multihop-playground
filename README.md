# 泊序 Evidence atlas

一个无构建依赖的静态证据核对工作台。默认任务为电动牙刷归类的历史裁定教学：确认商品事实，阅读原文短摘录，选择下一查证方向，并查看带来源的阶段结论。

## 运行

在本目录执行 `python3 -m http.server 8080`，浏览器打开 http://localhost:8080 。需要通过 HTTP 加载 JSON，不建议直接双击 HTML。

## 材料核对工作台

- 以美国 CBP 的 HQ966794（2004）、HQ087396（1990）、HQ965440（2002）三份历史官方裁定为材料。
- 整机、单独刷头、关键事实不明分别进入不同路径；还可选择更接近的牙刷前案或另一电机商品类比。依据不足时停止并列出需补材料。
- 改动关键属性或回退改选将清除失效的后续路径，不沿用旧结论。
- 文件、原文片段及关系可点击；来源卡将官方原文短摘录与中文解释分区，精确高亮对应文字，保留原文字符位置和官方链接。
- 分支、理由和事件提示均是作者依据官方材料编排的教学回放，不是新增模型实验、实时检索或推理。历史美国税号不能直接用于中国或当前申报。

## 独立研究回放

保留既有多跳检索实验 H174030（增益）和 H029876（退化）的真实记录，以及单独的关联教学示意。实验数据摘自 2026-09-14 已完成的离线研究；不与新的电动牙刷教学流程混算指标。引文恢复率不等于估价准确率。

## 发布文件

`index.html`、`style.css`、`app.js`、`data.json`、`product.css`、`product.js`、`toothbrush-case.json`、`README.md`。

无密钥、模型权重、原始论文或私人报关材料。无 CDN 和外链字体，不调用模型、不上传用户资料、不提供自动关税决定。仅发布演示代码、整理后的公开来源短摘录与获准展示的既有实验轨迹。额外核验记录不属于部署文件。

## 交互与可访问性

工作台与研究回放切换、商品属性核对、多方向选择、回退清理、补证停止、来源高亮、证据关系解释、原有逐轮播放与比较。保留原生按钮、键盘焦点、可聚焦横向图谱和减少动态效果偏好。
